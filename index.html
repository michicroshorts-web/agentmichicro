MichiCroShorts

A desktop tool to manage, schedule, and upload short-form video content to TikTok.

What it does

MichiCroShorts is a desktop content management tool for TikTok creators. It helps you organize and upload your video content efficiently.

  • Upload videos to TikTok via the official API
  • Manage and categorize your video content
  • Batch upload support for multiple videos
  • Simple command-line interface

Getting started

MichiCroShorts is a personal desktop application. To use it, you need a TikTok account and authorized API access.
